# Bird Rights Keeper League

Сайт фентези-лиги: таблица, матчапы, команды, правила и история. Статические страницы собираются
из JSON-файлов в `data/` и устава `rules.md`, публикуются на GitHub Pages (https://birdrights.ru).

Данные обновляются автоматически каждый день в 09:00 UTC (12:00 МСК) через GitHub Actions.

## Как обновить устав

1. Откройте `rules.md` и поправьте текст (прямо на GitHub: карандаш «Edit this file»).
2. Сохраните изменения (Commit changes). Через 1–2 минуты сайт пересоберётся сам.

Правила разметки: раздел — строка `## 1. Название` (номер попадает в оглавление), подраздел — `### Название`,
вводная плашка раздела — строка, начинающаяся с `>`, пункты — нумерованный список `1.`, `2.` …

## Как переопределить имена менеджеров

Откройте `data/managers_override.json`. Для каждой команды там есть запись с номером команды в ESPN:

```json
"1": { "team": "Far East Dynasty", "manager": "Leon" }
```

Впишите имя в поле `manager`. Пустое значение — на сайте будет ник из ESPN. Поле `team` — подсказка,
оно обновляется автоматически. Новое имя появится на сайте после следующего обновления данных
(или запустите его вручную, см. ниже).

## Как вручную запустить обновление данных

На GitHub: вкладка **Actions** → «Обновление данных и публикация сайта» → **Run workflow**.

Из терминала:

```bash
gh workflow run site.yml
```

## Секреты

`LEAGUE_ID`, `ESPN_S2` и `SWID` хранятся только в GitHub Secrets
(Settings → Secrets and variables → Actions) и в локальном файле `.env`, который не попадает в репозиторий.
Куки ESPN со временем перестают действовать: если обновление в Actions падает на шаге «Выгрузка данных из ESPN»,
возьмите новые значения `espn_s2` и `SWID` в браузере на espn.com и обновите секреты.

## Локальный запуск

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python scripts/fetch_data.py
.venv/Scripts/python scripts/build.py
.venv/Scripts/python -m http.server 8765 --directory _site
```

Проверка вёрстки со скриншотами (нужен Playwright: `pip install playwright`, затем `python -m playwright install chromium`):

```bash
.venv/Scripts/python scripts/check_site.py
```

## Что где лежит

| Путь | Что это |
|------|---------|
| `rules.md` | устав лиги |
| `data/*.json` | данные ESPN, обновляются скриптом |
| `data/managers_override.json` | имена менеджеров |
| `data/history.json` | сезоны и чемпионы |
| `data/<год>/` | архив завершённого сезона |
| `scripts/fetch_data.py` | выгрузка данных из ESPN |
| `scripts/build.py` | сборка сайта в `_site/` |
| `templates/`, `assets/` | шаблоны страниц, стили, шрифты, логотип |
| `.github/workflows/site.yml` | ежедневное обновление и публикация |

## Новый сезон и история

Номер сезона определяется автоматически (с сентября — следующий год, как в ESPN). Когда финал плей-офф
сыгран, скрипт сам добавляет сезон в `data/history.json` (чемпион, финалист, победитель регулярки,
итоговая таблица) и копирует данные в `data/<год>/`. Пока новая лига на ESPN не создана,
на сайте остаются последние данные.
